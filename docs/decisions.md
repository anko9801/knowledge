# 決めたことと、決めていないこと

**このリポジトリは複数のセッションが同時に触る。** 2026-08-21 には push が
非 fast-forward で 5 回弾かれ、同じ連載を別々の判断で削る、という取り違えも起きた。

`docs/build.md` は**仕組みの説明**で、ここは**判断の記録**である。
なぜそう決めたか、そしてまだ決めていないことを置く。
コミットメッセージにしか無い理由は、探せないので消えたのと同じになる。

書くときは日付を付ける。撤回したものは消さず、取り消し線ではなく
「撤回」の節へ移して理由を残す。同じ議論を二度しないためにある。

## 決めていないこと

**決める前に、ここを読んでほしい。** 片方だけ直すと食い違う。

### λ 計算と Curry–Howard をどちらの連載の正典にするか

`lambda-calculus` / `simply-typed-lambda` / `curry-howard` を、
形式意味論 第 1 回（`linguistics/semantics/1`）が `provides` している。
いっぽう `cs/types`（型と計算）も同じ範囲を扱う予定で立っている。

概念グラフは複数の記事が同じ概念を provide してよい（経路の選択肢になる）ので
壊れないが、本文が二重になる。どちらかを正典にして、もう片方から参照するのが自然。

**cs 側を正典にするのが筋だと思う。** 形式意味論は λ 計算を道具として
使う側で、型理論そのものを主題にしていない。ただし cs/types をまだ書いていないので、
書く人が決めてよい。

## 決めたこと

### 「損失は三つ数える」を撤回した（2026-09-02）

**反証された。しかも規則が、例の何が効いているかを取り違えていた。**

#### 数はこの読者に効かない

Petty & Cacioppo (1984)。論拠 3 個対 9 個、強対弱、関与の高低で交差。

| 関与 | 結果 |
| --- | --- |
| 低い | 論拠が多いほど説得される。**質はほとんど効かない** |
| 高い | **強い論拠だけが効く。弱いものを増やしても効果なし** |

**数は周辺的な手がかりで、考えていない読者にだけ効く。**
物理の導出を自分から読む人は関与が高い側なので、数を揃えても何も買えない。

#### 弱いものを足すと、強いものまで下がる

Obermaier & Koch, *Scientific Reports* (2024)、4 実験。
**人は論拠を足さずに平均する。**

| 強い論拠に足すもの | 結果 |
| --- | --- |
| 中くらいの強さ | 加算的。上がる |
| **弱いもの** | **平均されて、強い論拠の効果が下がる** |

同じ向きの結果が複数ある。Weaver らの「Top 10 reasons」は、専門家が訴求を
強めようとして弱めた例。Sivanathan & Kakkar, *Nature Human Behaviour* (2017) は、
薬の広告で軽い副作用を重いものと並べると危険の認識が薄まることを示している。
起源は Nisbett, Zukier & Lemley (1981) の希釈効果。

#### 直した先

`writing.md` の例（時間・ウルト・合流の三つ）は**そのまま残す。**
効いているのは三つだからではなく、**三つとも具体で強さが揃っている**から。

規則の文言を「三つ数える」から**「弱いものを足さない」**に変えた。
中くらいの強さなら足してよい。**一つしか無ければ一つでよい。**

#### 適用の注意

出典は説得（態度変容）の研究で、この site は説明が主である。
ただし**この規則自体が説得の規則**（「損得で書く」の一部）なので、
分野の取り違えではないと判断した。

### 実例の数と、終わり方に外の測定を当てた（2026-09-02）

#### 実例は二つ要る（支持。しかも一つでは代用が効かない）

Gick & Holyoak, *Cognitive Psychology* 15(1), 1–38 (1983)。

| 条件 | Duncker の放射線問題を解けた割合 |
| --- | --- |
| 類例なし | 約 10% |
| 類例が一つ | 約 30% |
| 類例を二つ、比べさせる | さらに大きく上がる |

**効くのはここ。** Part I が、**一つの類例から原理を引き出させる工夫**を三つ試している
── 要約させる、原理を言葉で述べる、図示する。**どれも効かなかった。**

だから「実例を一つ出して、原理を説明で補う」は成立しない。
`writing.md` の「気づくのは読者（作者が先に答えを言わない）」も同じ実験が支持している。

**二つ在ればよいのではなく、比べさせる必要がある。** schema は
「二つの類似点を述べることの副産物」として出てくる。並べて、同じ形だと言わせる。

#### まとめで終わらない（規則は残すが、理由が違っていた）

**要約は有害ではない。** 与えるだけでも保持は上がる。上がらないのは転移のほう
（Wang ら 2023）。学習者に書かせると転移も上がる（中央値 d = 0.50、30 実験中 26 で優位）。

**与えられた構造はむしろ効く。** 指導者提供のアウトラインで、記憶に g+ = 0.61、
理解に g+ = 0.34（*Educ. Res. Rev.* 2023 のメタ分析）。

そして危ない条件がある。**desirable difficulties は、要素間の相互作用が高い教材では
逆効果になる。** 物理の導出はそこに当たる。

だから、この規則を**「構造を与えるな」と読むと間違い。** 禁じてよいのは
**見出しを言い直すだけの表**で、あれは構造を足していない。
`summary` の欄も、途中の整理の表も、続ける。

規則そのものは残す。ただし理由を「要約が悪いから」ではなく
**「終わりは対照を置く場所だから」**に直した。前者は測定と食い違う。

### 誤解を名指す形と、脱線の代償を測った（2026-09-02）

書き方の規則のうち二つに、外の測定を当てた。**片方は支持され、片方は反証された。**

#### 誤解を名指してから正す形（支持）

| 出典 | 規模 | 効果量 |
| --- | --- | --- |
| Schroeder & Kucera, *Educ. Psychol. Rev.* (2021) | 44 比較、n = 3,869 | g = 0.41（理科だけだと 0.45） |
| Danielson ら, *Educational Psychologist* 60(1), 23–47 (2025) | 71 論文・76 研究・294 効果量 | 一貫して有利。**26 の調整変数がどれも効果を変えなかった** |

refutation text と呼ばれる形。ただ正しく書くより、**読者の誤解を名指してから
正すほうが効く。** 頑健で、文脈によって消えない。

**機構に条件が付く。** Kendeou & van den Broek によれば、正しい概念と誤った概念が
**同時に活性化する**ことが効き目の源。だから**隣に置く**必要があり、
節を分けると効かない。

`CLAUDE.md` の「会話の決着を、記事に書かない」と衝突しない。あちらが禁じているのは
**会話の相手にしか通じない前提**を否定することで、refutation text が扱うのは
**読者が実際に持ってくる通説**のほう。2026-09-02 に足した範囲の線が、
これで裏付けられた形になる。

なお `writing.md` の「反対側に立たせる」とは別物。あちらは視点の交替で、
こちらは誤った命題の名指し。

#### 本筋にゼロの脱線（反証）

`writing.md` の「説明を続けない」が「落ちを付けて捨てる脱線」を勧めている。
これは seductive details そのもので、**測ると負の効果が出る。**

| 出典 | 規模 | 効果 |
| --- | --- | --- |
| Rey, *Educ. Res. Rev.* (2012) | 39 の実験効果、25 年分 | 保持に小〜中、**転移に中**。どちらも負 |
| Sundararajan & Adesope, *Educ. Psychol. Rev.* (2020) | メタ分析 | 効果の大きさが複数の要因で変わる |

機構は Harp & Mayer。**因果の鎖の途中に挟むと、鎖を組み立てる処理を妨げる。**

**規則は残した。** この site の読者は題材を選んでいないので、閉じられたら保持は
ゼロになる。動機の側の利得を測っていないため、比較が成立しない。
ただし**代償が測られている以上、置き場所を縛る**ことにした
（導出の途中と、誤解を正している最中には置かない）。

反証を採らなかった理由を残しておく。**測っているのは指示された学習で、
こちらは自発的な読書である。** 転移テストを受けない読者にとって、
転移が下がることの意味が違う。**それでも代償は実在するので、無視ではなく制限にした。**

### 制約の本数を四つに揃えた（2026-08-28）

README が「三つ（機械・人・時間）」、`taxonomy.ts` の blurb と
`programs/01` の題名が「四つ（機械・保持・誤り・変更）」で、
**読者が見る二箇所が食い違っていた。** `concepts.ts` の注釈は
「数えると四つではなく三つだった」と書いてあるのに `irreducible-inputs` の

**四つに揃えた。** 保持と誤りを一本に潰すと、すべて覚えていられても混入する率は

`feasibility-vs-cost` の gist。

**rebase で拾った。** 同じ日に別セッションが `error-proneness` の名を

### 分野をまたぐ重複は、三つの型に分けて処理する（2026-09-06）

#### 型 A ── 同じ結論に、導出が二本

排他律。量子力学は**対称化の要請**から出し、場の量子論は微視的因果律と

### 観測量を、有限次元のスペクトル定理に繋いでいた（2026-09-06）

作用素論の調査が、既存データの誤りを見つけた。

```ts

c('spectral-theorem', 'スペクトル定理', '自己随伴なら正規直交固有基底が取れる', …, ['self-adjoint', 'diagonalization'])
```

**二重に間違っていた。** 位置にも運動量にも自由 Hamiltonian にも固有ベクトルは
$L^2$ の中に無い。しかも指していた `spectral-theorem` は `diagonalization` を
要求しており、**有限次元版**である。

直した形。`observable` の要旨から固有基底の主張を落とし、`analysis.ts` に
非有界版を立てて、そちらを指す。**有限次元版は消さない**（型 B。
`linear-algebra.ts` の側は `diagonalization` を要求し、非有界版は要求しない）。

Teschl **定理 2.9**（本文で確認）── 全空間で定義された対称作用素は有界。
つまり**定義域を書くのは丁寧さではなく、書かないと定理に反する。**

### 要請に名前が付いていない連載は、まだ軸が書けていない

同じ調査が、量子力学に**時間発展の概念が一つも無い**ことを見つけた。
Hilbert 空間・状態・観測量・Born 則・合成系・対称化しか置いておらず、
Schrödinger 方程式に対応する id が存在しなかった。

`energy-bounded-below` も無かった。`antiunitary-time-reversal` の要旨が
**「下に有界という仮定と衝突する」と書いているのに、その仮定に id が無い。**
`positive-definite-metric` を代わりに指していた。

両方を立てて、Stone の定理と対にした。**要請を概念として立てていない箇所は、
`derivations.ts` の対が書けないことで機械的に見つかる。**

### 型を当てはめすぎた。検査が止めた

上の作業で `observable → spectral-theorem-unbounded` を `derivations` に書き、
同時に `requires` にも書いた。**検査が落とした。**

正しくは素の依存である。「観測量とは何か」を言うのにスペクトル定理が要る、
という論理的な依存であって、**仮定が定理に変わる関係ではない。**
仮定→定理と言えるのは、`observable` が「エルミートで足りる」と置いていること
（→ `symmetric-vs-selfadjoint` が定義域の差を示す）のほう。

**型は当てはめるものではなく、当てはまるかを見るもの。**

### 分野をまたぐ辺は、三種類ある（2026-09-07）

`derivations.ts` を作ったとき、分野をまたぐ関係は二つだと思っていた ──
依存（`requires`）と、仮定→定理（`Derivation`）。**三つ目があった。**

**狭い設定で成り立っていたことが、広い設定では偽になる。**

| 狭い設定で成り立つ | 広い設定で偽 | 見つけた調査 |
| --- | --- | --- |
| 初期値を与えれば解が一意（Picard--Lindelöf） | 弱解は一意でない | 偏微分方程式 |
| 自己随伴なら正規直交固有基底が取れる | 位置にも運動量にも固有ベクトルが無い | 作用素論 |
| 時間発展はユニタリで可逆 | 熱方程式は半群にしかならない | 同上と偏微分方程式 |

**三つの調査が、互いに知らないまま同じ形に当たった。**それが根拠である。

`requires` では書けない（依存ではない）。`Derivation` でも書けない ──
あちらは「仮定が定理になる」で、こちらは**「定理が偽になる」**。向きも内容も逆。

`src/data/concepts/limits.ts` に `Limit` として置く。`npm run curriculum limits`。

**なぜこれを主題にできるのか。** 教科書はここを黙って通り過ぎる。前の章で証明した
定理が次の章では成り立たない、と書いてある本は少ない。**読者は自分の理解を疑う。**
そこを正面から扱えるのは、分野をまたいだ地図を持っているからである。

三つとも二重に書かない（`requires` にも `derivations` にも）ことを検査が見ている。
**どれが効いているのか読めなくなるため。**

### 21 本の分野調査の、家の決め方（2026-09-06〜07）

**調査そのものの索引は `docs/surveys.md`。**ここに残すのは、
**もう一度考え直さなくてよい判断**だけである。

| 決めたこと | 根拠 |
| --- | --- |
| **投票理論は社会科学、メカニズムデザインは経済学** | 線は「貨幣が無い / 支払いがある」。Arrow も中位投票者も Balinski–Young も Banzhaf も**仮定が順序だけ**で、効用も予算制約も要らない |
| **Legendre 変換の家は凸解析** | 「Legendre 変換」は `aka` へ。物理の読者は全員 Legendre で探しに来て、凸解析の本には Fenchel としか書いていない |
| **Huygens（奇数次元でだけ鋭い）の家は偏微分方程式** | 波動方程式だけから出て、Maxwell 方程式は要らない。電磁気は引く側 |
| **有限体と Galois は代数** | 初等数論は Galois を一度も使わず、代数体も最初の六章は使わずに書ける。数論に置くと、数論の前に体論を全部読ませることになる |
| **Neyman–Pearson は統計に一つだけ** | 医学は動作点の選び方、心理は「一つの正答率が二つの数に分かれる条件」。三つの調査が同じものを別々に挙げていた |
| **エルゴード理論は三つに割る** | 「時間平均は必ず収束する」（Birkhoff、力学系）と「位相平均に等しい」（要請、統計力学）を潰すと、`observable` を有限次元スペクトル定理に繋いでいたのと同じ失敗になる |
| **Liouville の定理（位相体積）の家は統計力学** | シンプレクティック形式が閉じていることだけから出る。**複素解析の Liouville と名前が衝突する**ので、両方の `gist` に別物だと書いてある |
| **流体の家は流体力学** | 移動現象論（工学）も地球流体力学も、Navier–Stokes と Reynolds 数を引くだけで再定義しない |

**統合しないと決めたもの。**

- **選択則と Woodward–Hoffmann は機構が違う。**片方は Wigner の消滅積分定理
  （**一点の点群**）、片方は非交差則（**経路全体で保たれる部分群**）。
  「対称性が禁じる」に二つの意味がある、が連載の結びになる
- **Hall の定理と安定マッチングは無関係。**Gale–Shapley の設定はグラフが完全二部で、
  Hall の条件は自明に成り立つ。中身は全部「安定性」の側にある
- **Balinski–Young は Arrow の実例ではない。**要求も結論も別
  （quota rule と人口単調性 対 全会一致と IIA）。**不可能性定理が二つある**
- **薬物動態は薬理学と切り口が違う。**「何に効くか」は経験、「質量保存と一次速度論を
  仮定したとき濃度がどうなるか」は線形常微分方程式を解いて出る。
  同じ形が二つ ── 生化学は × だが酵素反応速度論は ◎、生理学は × だが循環・呼吸の定量は ◎

**数え方が分け方を決めた。**

- **数論は二本。**軸が違う（合同の中で閉じる 対 整数環を取り替える）。
  分ける根拠がそのまま `derivations` の一行になる ── 初等数論は Pell の無限解を
  連分数で作り、なぜ在るのかは言わない。代数体は実二次体の単数の階数が 1 であることから出す
- **組合せ論とグラフ理論は一本。**平面性・彩色も極値・確率的方法も単独では 10 に届かず、
  一本の軸で繋がる ── **「その形が入らない」ことは、入らない理由を一つ挙げて示す。
  理由が挙がらないときだけ確率が要る**
- **工学は三本に割った。**制御・移動現象論・構造力学。三つとも独立に ◎ で、
  一本にまとめる理由が無かった。残り 9 概念は `engineering.ts` に置いてある

### 対角化が五箇所に散らばっていた（2026-09-07）

`cantor-theorem`（集合論）、`diagonal-lemma`（論理）、`tarski-undefinability`、
`halting-problem`、`time-hierarchy`（計算量）── **全部 Lawvere の不動点定理の対偶で、
辺が一本も無かった。**

デカルト閉圏で $f: A \to B^A$ が点全射なら $q(a) = g(f(a)(a))$ が $g$ の不動点を作る。
対偶に $g = not$ を入れると Cantor、文の集合に入れると Tarski、停止判定に入れると
停止問題、対角化に入れると時間階層定理。

**五本とも `derivations` に置いた。**各連載が対角線を**手として**置いていて、
それが一つの定理だとは言っていない ── その形は「よその仮定を出す」に当たる。

### 分離超平面に、四人が独立に着いた（2026-09-07）

経済学（無裁定と状態価格の同値）、工学（塑性崩壊の下界定理）、
哲学（**Dutch book ── 整合性 ＝ 裁定不可能性 ＝ 確率測度の存在**）、
化学（Lieb による密度汎関数の凸解析的定式化）。

**畳まない。**四つとも仮定が違い、結論も違う。畳むのは `separating-hyperplane` への

`decision-theory.ts` の `same-theorem-as-no-arbitrage` が、そのうち二つを明示的に結ぶ。

### 分野をまたぐ同じ定理が、あと三つ見つかった（2026-09-07）

不動点・分離超平面・Legendre・くりこみ群に続く。**三つとも、概念は既に在って辺が無かった。**

- **不確定性関係は Cramér–Rao の一般化である。** Dembo–Cover–Thomas 1991 §IV が逐語で
  "the Cramer-Rao inequality for location parameter is **exactly** the
  Weyl-Heisenberg uncertainty principle" と書いている。**Heisenberg = Stam の不等式
  ⊕ Cramér–Rao** で、位相を持つぶんの差をちょうど Stam が埋める。
  回折限界も同じ不等式（開口と角度が Fourier 共役）
- **交換可能なら独立同分布の混合で書ける。** Hewitt–Savage。集団遺伝学の
  Kingman のペイントボックスは**類似ではなく de Finetti 測度そのもの**
  （Broderick–Pitman–Jordan が逐語）。量子版は QKD の安全性証明が乗っている。
  **縫い目まで著者が書いている** ── 経験測度に量子の対応物が無いので、
  有限量子版は次元に依らざるをえない
- **平等さは半順序で、単調量ひとつでは決まらない。** Hardy–Littlewood–Pólya の優越。
  経済の Lorenz 優越、量子の Nielsen、熱力学の thermo-majorization。
  **いちばん値打ちがあるのは否定のほう** ── $(2\/3, 1\/6, 1\/6)$ から
  $(1\/2, 1\/2, 0)$ はエントロピーが増えるのに移れず、
  しかも別の単調量に取り替えても直らない（Ruch–Lesche 1978）

### 二つの Bode の定理を、同じ前提に繋いでいた（2026-09-07）

**利得位相関係と積分定理は別の定理である。** 前者は Titchmarsh を $\ln L$ に
当てたもので**最小位相を仮定する**。後者は右半面の零点・極を Blaschke 積として
括り出すので、**まさにそれを仮定しない**。両方を `causality-is-analyticity` に
繋いでいたのを、後者は `all-pass-factorization` 経由に直した。

**積分定理は不等式ではなく等式である。**「押さえた分だけ持ち上がる」は保存則の
読み替えで、不確定性関係の仲間ではない ── 証明に内積も共役対も出てこない。
日本語が同じだけで畳みかけた。

### 調べて、繋がらなかったもの（2026-09-07）

**負けた仮説のほうが値打ちがある**ので残す。

- **Nielsen–Ninomiya = Brillouin トーラス上の Poincaré–Hopf は偽。**
  英語版 Wikipedia がそう書いているが、当たれた資料はどれも支持しない。
  消えるのは Hamiltonian 束の Euler 類（ファイバー次元が奇数）で、
  **底空間の接束ではない**。Bloch Hamiltonian はトーラス上の接ベクトル場ではない
- **FLP と Arrow は同じ証明ではない。** FLP は二価性と敵対的スケジューリングで、
  決定的連合もフィルタも独立性公理も出てこない。似ているのは
  「入力を一つずつ変えて切り替わり点を取る」手つきだけ
- **H 定理 = 優越 は偽。** 一方向のみ（上記の反例）
- **帰属の誤りが二つ。** J 積分の Noether 解釈は Rice でも Eshelby でもなく
  **Günther 1962 / Knowles–Sternberg 1972**。球面上の欠陥の和則は Mermin 1979 ではなく
  **Lubensky–Prost 1992 / Nelson 2002**。どちらも「記憶で引くと外す」型

### 残っていた ◎ を全部入れた（2026-09-07）

分類体系の調査で ◎ が付いていたもののうち、未着手だった 9 本。

**物理**（原子核・プラズマ・磁性と超伝導・格子ゲージ）。四つとも
**「導けないものが在ることを、毎回はっきり言う」**形になった ──
核力は標準模型から出ず、渦粘性も異常輸送も当てはめ、
高温超伝導の機構は決まっていない。`five-coefficients-are-fitted` のような
概念を各連載に一つずつ置いて、そこを主題にしてある。

**規準にまっすぐ合うもの**（誤り訂正符号・数理ファイナンス・判断集約）。

- **符号は上下から挟む形。**Singleton・Hamming・Plotkin が上、
  Gilbert–Varshamov が下。**隙間が二元符号で 70 年埋まっていない**ことまで含めて、
  「何を要求すると両立しなくなるか」がそのまま連載になる
- **ファイナンスは二つの基本定理が二段を分ける。**無裁定 → 測度が在る、
  完備 → 一意。**無裁定だけでは値段が付かない**が芯
- **判断集約は三つ目の不可能性。**Arrow は選好と推移性、Balinski–Young は
  配分と単調性、こちらは命題と無矛盾性。**要求も結論も共有していない**ので、
  `three-impossibilities-differ` で明示的に区別を書いた

**数学**（表現論・可換環論と代数幾何・モデル理論と証明論）。

- **表現論の軸は「分類が本当に終わる」**。有限群は指標表、単純 Lie 環は
  四系列と五例外。**尽きたことが定理である**
- **代数幾何は「図形と環が同じもの」**。代数体の整数環と滑らかな曲線が
  同じ枠に入る（Dedekind 環＝一次元で正則）ところで、数論と繋がる
- **モデル理論はコンパクト性を道具として使う側**。既存の `compactness-theorem` は
  完全性定理の系として置かれたまま、使う場所が無かった

### 平均場近似を `Limit` として置いた（2026-09-07）

**狭い設定で成り立ち、広い設定で偽になる**の三つ目。

Curie–Weiss は転移温度も臨界指数も出すが、**一次元では在りもしない転移を予言する。**
転送行列で厳密に解けるので、間違いだと確定している。二次元では連続対称性について
同じことが起き、四次元より下では指数を外す。

**外れる場所が全部次元で決まっている**ので、`where-mean-field-fails-is-known` を
一つ置いて、そこから既存の `mermin-wagner` と `upper-critical-dimension` へ繋いだ。

そして超伝導では逆に**平均場がほぼ厳密**（対の大きさが平均間隔より大きいので
ゆらぎが効かない）。**同じ近似が、場所によって当たり外れが逆になる**が結びになる。

### 横断の残り二つと、常微分方程式（2026-09-07）

**Noether と Bellman は一つの連載に畳んだ。**根が同じで、
変分問題を経路の側から見るか値の側から見るかの違いでしかない。

- **Noether は力学の定理ではない。**変分構造さえあれば効くので、
  破壊力学（J 積分の経路独立性）・最適制御・最適成長の三つが、
  力学を経由せずに同じ定理を使っている
- **Bellman 方程式は Hamilton–Jacobi 方程式である。**特性曲線が正準方程式、
  共状態が価値関数の勾配、繋ぐのが Legendre 変換。min-plus に落とすと
  Bellman–Ford が Jacobi 反復、Floyd–Warshall が Gauss–Jordan になり、
  転送行列の Perron 固有値が、温度をゼロへ送ると最大巡回平均に落ちる

**ただし「全部同じ」とは書かないこと。**個々の対応は定理だが、
**統一原理そのものは定理ではない** ── Litvinov 自身が対応原理を
"clearly, a heuristic one" と書いている。`correspondence-is-heuristic` を
最後に置いて、そこを明示してある。

**常微分方程式は、既存の下が抜けていた三つ目。**`ode-existence` が
17 箇所から参照されているのに、下が 1 概念しか無かった
（関数解析＝量子力学の下、精神物理＝色彩と音律の下、と同じ形）。

軸は**「解けないほうが普通で、解けるものには理由がある」**。
存在定理は解が書けることを一つも言っていない、というのが
そのまま `derivations` の一行になる。

結びは境界値問題で、**四つ目の `Limit`** になった ──
初期値問題では必ず一意に存在したものが、条件を両端で与えると
存在しないことも無限にあることもある。**方程式は何も変わっていない。**

見つけられない**（`hardness-of-learning`）。ここは計算量理論だが、1 概念のために
連載は立たない。

**外向きの辺が一本も無かったので、綺麗に落ちた。** `regret-minimization` が
`online-competitive-ratio`（アルゴリズムと下界）を要求していただけで、
逆向きは無い。もう一度足すときも閉じた 12 個で済む。

**反論として一つ残しておく。情報理論も同じ性質を持っている。** あちらも中核は
確率論で、`entropy` は `expectation` を要求するだけである。それでも cs に置いて
記事を 3 本書いてある。だから「数学で閉じるから cs ではない」を一般則にすると、
情報理論も外れる。**線は「数学で閉じるか」ではなく、「計算機の側で何が導けるか」に
引くこと。** 情報理論には符号化定理と通信路容量があり、学習理論の側には
`hardness-of-learning` の 1 個しか無かった。そこが差である。

### 「記事内の参照は peek を切る」（2026-08-23 に決め、同日に撤回）

決めた理由は「謎解きは大謎の材料を忘れさせるのに、peek は常に思い出させる。
だから同じ記事の中で peek を付けるのは、忘れる余地を潰している」だった。

**実装の前に測って、前提が間違っていたことが分かった。**

peek が添えているのは 621 件で、**参照先はすべて statement**（定義・定理・命題・
補題・系・公理）である。いっぽう大謎の材料は**構造的な気づき**のほうで、
ベクトル解析 1 の「3 次元で k 形式の成分は 1, 3, 3, 1 個」は `#table` で書かれていて、
そもそも peek の対象ですらない。

**この二つは重なっていなかった。**「定義 5」を思い出させることは、大謎を殺さない。
「参照」という一語だけで二つを同一視していた——差を数えずに同一視するという、
[writing.md](writing.md) に書いたばかりの失敗そのものである。

そして距離を測ると、元の理屈（分割注意）のほうが正しかった。

| 参照元と参照先の行距離 | 件数 |
| --- | --- |
| 0〜10 行 | 61 |
| 11〜25 行 | 116 |
| 26〜60 行 | 178 |
| 61〜120 行 | 116 |
| 121 行以上 | 150 |

**71% が 25 行より遠い**（中央値 49 行、最大 1029 行）。往復コストは実在する。

さらに `peek.ts` の `asPeek` は最初から `<details>` を落としていて、
**想起の問いを参照したときに答えが漏れない配慮は既に入っていた。**

残った論点は、下の「すぐそこを指す参照には添えない」で片付けた。

## 同時に走るときの作法

- **調査の agent は 6〜8 本まで。** 同時実行の上限は 20 本だが、**20 本まで出すと
  セッションの利用上限に当たって全部落ちる。** 2026-09-06 に二度踏んだ
  （12 本と 15 本が同時に落ちた）。最初に出した 8 本は全部完走している。

  しかも**調査の agent は自分の子を走らせる**ので、8 本出すと実際には 15〜18 本になる。
  `ListAgents` で数えてから足すこと。**落ちても報告は返らない** ──
  途中まで進んだ調査が丸ごと消える（1 本 15〜25 分）。

- **検索の予算もセッション単位で尽きる。** 「WebSearch の予算が尽きた」で終わった
  報告が 4 本あった。一次資料の URL が分かっているものは**検索させず、
  `WebFetch` する URL を仕様に書いて渡す。** 全文公開の教科書はそれで本文まで取れる。

- **`nix develop` の外で走らせない。** 外の typst は 0.14.2 で、
  **MathML export（0.15 で入った）を持っていない。** `flake.nix` が typst だけ
  unstable から取っているのはそのためで、6 行目に書いてある。
  外で走らせると二段階で失敗する。まず `prebuild` の MathML 抽出が
  「`<head>` に `<style>` がありません」で落ち、次に `typst eval` が
  `unrecognized subcommand` で落ちて content の sync ごと止まる。
  **どちらのエラーも原因を指していない。**
  2026-08-28 に、これを「typst 0.14.2 で API が消えた」と誤診して
  `typst-cli.ts` を `query` へ書き換えかけた。動いているコードを古い側へ
  戻すところだった。**バージョンが合わないときは、まず `flake.nix` を見ること。**

- **worktree で作業するなら、本体の checkout にも `npm ci` しておく。**
  `astro check` が `Tsconfig not found astro/tsconfigs/strict` で落ちるときはこれである。
  vite（rolldown）は tsconfig を上のディレクトリまで探しに行くので、
  `.claude/worktrees/*` から見て親にあたる本体の `tsconfig.json` を拾う。
  そちらに `node_modules` が無いと、`extends` が解決できずに sync ごと止まる。
  **worktree 側の `tsconfig.json` をいじっても直らない**（`extends` を消しても同じ
  エラーが出る）。原因は隣ではなく上にある

- **rebase のあとに `npm run verify` を回し直す。** 別セッションが同じファイルを

- 連載の構成・本数・分野の増減を変えるときは、このファイルに一行書いてから変える
