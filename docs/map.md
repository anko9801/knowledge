# 扱う主題の地図

**これは待ち行列ではない。** 全体に何があるかを一枚にしたもので、書く順とは別である。

書く順を穴の順にすると、題材が「何を導けるか」ではなくグラフの穴で決まる。
88 本がどれも同じ顔をしていた根がそこにある（`CLAUDE.md`）。
**地図は隣に何があるかを見るためにあり、埋めるためにはない。**

判定は二つで通す。

| | |
| --- | --- |
| **何を仮定したら形が決まるか**が言えるか | README の元からの基準 |
| **導ける結果を数えられるか** | 2026-08-28 に追加。学習理論は 1 個で落ち、情報理論は符号化定理 2 本と容量で残った |

「立つ」は主題として成立するもの、「保留」は判定を先送りにしたもの、
「立てない」は理由つきで落としたもの。撤回の記録は `decisions.md`。

#### 中謎と大謎

**中謎（第 1 回で開けて閉じる）** 粒子と呼んでいるものは、どこにあるかを言えない。
**大謎（最後まで残す）** 場の量子論は素粒子の基礎理論ではなく、低エネルギーで
見えている形の総称である。第 17 回で閉じる。

**第 6 回（スピン統計定理）を到達点にしないこと。** `reader.md` の
「強い素材を到達点にしない」に従うと、Pauli の排他律は中盤の山である。

**第 9 回がいちばん repo 向き。** 摂動論も相互作用の詳細も使わずに、Poincaré
不変性・正エネルギー・完全系の三つだけで 2 点関数の形が決まってしまう。
「何を仮定したら形が決まるか」そのものである。

**統計力学が先に要る。** あちらは「一つの状態に何個入れるか」を外から与えて
分布を二つに分ける。読者がそこを一度通っていないと、第 6 回の
「その分岐が、選ぶものではなくなる」が効かない。

#### 伏線が二本張れる

**第 12 回がクラスター分解を回収する。** 真空泡は厳密に打ち消し（各図に同じ大きさで
逆符号の相棒が付く）、残るのは連結グラフだけになる。理由は、連結図は全体の
運動量の総和を縛るデルタ関数を一つしか持てないことで、**これがクラスター分解そのものである。**
第 3 回で場を導く根拠に使ったものが、グラフの形として戻ってくる
（`writing.md` の「途中の結果を部品に戻す」）。

破れる場合まである。エニオンでは、実在の励起の周りを回る位相的な真空泡が
編み込み位相を拾うので、打ち消しが部分的にしか起きない。
厳密なのはボースとフェルミのときだけ。

**第 14 回が第 1--5 回を回収する。** 「場は一点で値を持てない、演算子値超関数だ」と
置いておくと、発散の正体がそこから出る。

#### 調べて分かった、訂正すべきだったこと

**1. スピン統計定理は無から出ない。** Bose--Fermi の二択を先に仮定している。
局所性（Einstein 微視的因果律）が「空間的に離れた場の演算子は交換するか
反交換するかのどちらか」を与え、定理はそのどちらとスピンが組むかを決める。
ゴースト場は自分の共役と非因果的な反交換関係を持つので仮定を満たさず、
**他の Wightman 公理を全部満たしたまま結論を免れる。**

**2. 「反粒子が因果律を救う」は定理ではない。** 光円錐の外で粒子と反粒子の
寄与が打ち消す、という筋は教科書の語りである。厳密な中身は
**Hegerfeldt / Malament の定理**（どんな相対論的量子理論も、厳密に局在した
一粒子状態を持てない）と Reeh--Schlieder のほうにある。**より強くて、別の主張。**

**3. アノマリー相殺は「世代の中身を決める」とまでは言えない。** 縛るのは本当で、
混合ゲージ--重力アノマリーまで入れると電荷の量子化が出る（1 世代で
$6 times (+1\/6) = +1$ と $2 times (-1\/2) = -1$ が打ち消す）。だが**解は一意ではなく**、
エキゾチックな超電荷を持つ非標準解が存在する。**色の数は「奇数」までしか出ない**
（Witten の大域アノマリー）。$N_c = 3$ は実験（$R$ 比）から来る。
「アノマリー相殺が $N_c = 3$ を導く」は教科書の既知の誤りである
（クォークの電荷を固定したまま $N_c$ を変えるのが不整合なので循環する）。
世代ごとに相殺するのも**事実であって定理ではない**。

**4. Bose--Fermi を一語で混ぜていた。** 統計力学の Bose--Einstein /
Fermi--Dirac 統計は**分布**の話で、一つの状態に何個入れるかを外から与える。
場の量子論の二択は**演算子の代数**の話である。繋がってはいる
（$a^dagger a^dagger = 0$ なら占有数は 0 か 1）が、別の対象である。

**5. Weinberg の導出が repo の形そのものだった。** 場を量子化するのではなく、
粒子を Poincaré 群の既約表現として定義し、クラスター分解を満たす必要から
場を導く。「Lorentz 不変性・量子力学・クラスター分解から、場と粒子と反粒子の
形式全体が出る。局所性や因果律の補助的な仮定を置かずに」。
**ただし低エネルギーに限った主張で、弦理論が全エネルギー領域での反例になる。**

**電磁気を最初「ベクトル解析と重複する」として保留にしたのも誤りだった。**
重なると思っていたのは実際には**ベクトル解析 第 3 回の最後の 1 節**
（`03-exterior-derivative.typ:270`「ご褒美：Maxwell 方程式が 2 本になる」）で、
あれは**記法の話**である——Maxwell を与えられたとき、外微分で書くと 4 本が畳める。
物理側で問うのは逆で、**何を要請したら Maxwell が決まるか**。問いが違うので、
連載まるごとではなく 1 節と重なるだけになる。

**保留にするときは、重なる範囲を実際に見ること。** 題名から重複を推測して
二つとも落としかけた。

### 力学を「立てない」と判定したのは誤りだった

最初こう書いた——「解析力学がそれである。別に立てると、まず力で書く、次に力を捨てる、を
二度やることになる」。**二つの理由で外れていた。**

**一つ。順序が逆に効く。** 解析力学は `why-not-force`「力では理論を指定できない」から
始まる。これは `writing.md` でいう**痛み**で、読者がその痛みを実際に持っていないと
効かない。力を使ったことのない読者には、否定される対象が無い。
**力学が先にあるほうが、解析力学の入口は強くなる。**

**二つ。読者がどこから入るかを数えていなかった。** `writing.md` は
「読者は何も持っていない。下限は中学生に置く」と書いてある。いま `/physics` を
開くと最初に読めるのが解析力学で、そこがいきなり変分原理である。
**物理に入口が無い。** 導ける定理の数だけで測ると、この欠陥は見えない。

軸は解析力学と別になる。あちらが**理論をどう指定するか**で、こちらは
**与えられた理論が解けるか**である。対称性が一つ見つかるたびに次元が一つ落ちて、
落ちきったものだけが解ける。中心力は角運動量保存で平面に落ちて動径だけの問題になり、
剛体は主軸を取ると三つの独立な回転になり（`spectral-theorem` と
`quadratic-form`「主軸への変換」がそのまま出る）、連成振動は固有値問題になる。
落ちきらない例が三体問題。

**`normal-modes`（基準振動）は、いま化学にしか家が無い。** 連成振動の固有値問題という
力学の中身が、どこにも置かれていなかった。

## 確かめていないこと

`CLAUDE.md` の「引用は、確かめてから書く」に従って、
**一次資料に当たっていない主張をここに列挙する。** 記事にする前に確かめること。

- 代数の「角の三等分ができない」「五次方程式に解の公式が無い」が
  Galois 対応からどう出るか、証明の筋を追っていない
- 自然言語が文脈自由を超えるという結果（スイスドイツ語の交差依存）の出典
- 統計力学で「最大エントロピー原理から Boltzmann 分布が出る」の、
  仮定の正確な形
- ~~Malament の定理の仮定の正確な形~~ **確かめて第 1 回に書いた（2026-08-29）。**
  四つは「エネルギーが下に有界」「並進共変性」「局在可能性（交わらない領域の射影の積が 0）」
  「一瞬で滲み出さない」。四つ目は微視的因果律より**強い**条件で、Halvorson--Clifton が
  より弱い仮定から同じ結論を出す形に強化している。そして射影を POVM に緩めると
  **定理は成り立たない**（同じ二人の反例）。禁じられているのは位置そのものではなく、
  二値の判定のほうだった
- **九後汰一郎『ゲージ場の量子論』（培風館、新物理学シリーズ 23・24）は
  読んでいない。** 目次は書店の書誌から取った（上巻 5 章に BRS 対称性、
  特異系の正準形式、共変演算子形式での正準量子化、物理的 S 行列のユニタリー性、
  BRS 代数と四重項機構、ゲージ固定非依存性）。**中身の主張は引けない。**
  第 7 回の下敷きにするなら、箇所を確かめてから書くこと
- ~~Weinberg の folk theorem~~ **確かめて第 2 回に書いた（2026-08-29）。**
  機構は精密で、クラスター分解 ⟺ 係数関数が運動量保存のデルタ関数を一つだけ持つ
  （Weinberg 1964、4.3--4.4 節）。証明は Euler の公式 $C = V - I + L$ で、
  連結なら $C = 1$ からデルタ関数が一つに決まる。**摂動論で真空泡が打ち消して
  連結図だけ残るのは、これが形を変えたもの**なので、第 12 回で回収できる。
  ただし全体は定理ではない。低エネルギー限定（弦理論が反例）、
  $H_0 + H_"int"$ の分解を仮定、厳密版は Haag--Ruelle が別に建てている。
  **記事にもその三点を書いた**
