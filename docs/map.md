# 扱う主題の地図

**これは待ち行列ではない。** 全体に何があるかを一枚にしたもので、書く順とは別である。

書く順を穴の順にすると、題材が「何を導けるか」ではなくグラフの穴で決まる。
88 本がどれも同じ顔をしていた根がそこにある（`CLAUDE.md`）。
**地図は隣に何があるかを見るためにあり、埋めるためにはない。**

判定は二つで通す。

| | |
| --- | --- |
| **何を仮定したら形が決まるか**が言えるか | README の元からの基準 |
| **導ける結果を数えられるか** | 2026-08-28 に追加。学習理論は 1 個で落ち、情報理論は符号化定理 2 本と容量で残った |

「立つ」は主題として成立するもの、「保留」は判定を先送りにしたもの、
「立てない」は理由つきで落としたもの。撤回の記録は `decisions.md`。

## 数学

いま 9 連載・65 本・222 概念。ただし **9 連載のうち 5 つが一本の弧**である
（土台 → 線形代数 → ベクトル解析 → 微分形式 → Riemann 幾何、65 本のうち 35 本）。
残りが集合論・数理論理（22 本）と、群と表現・測度と確率（8 本）。
**幾何と基礎論の二本柱で、代数と解析が薄い。**

### 立っている

| 主題 | 何を仮定すると形が決まるか | 記事 |
| --- | --- | ---: |
| 集合論 | 素朴な内包公理が矛盾する。作る手続きだけを認めるとどうなるか | 12 |
| 数理論理学 | 証明そのものを対象にする。語る側と語られる側を分ける | 10 |
| 土台 | 幾何の連載が前提にしているもの | 6 |
| 線形代数 | 基底を選ぶのをやめると、何が本当の構造だったかが見える | 7 |
| 群と表現 | 対称性を測る道具。連続にすると多様体になる | 4 |
| 測度と確率 | 「測れる」を先に決めてから測る | 4 |
| ベクトル解析 | 3 次元でしか成り立たない偶然を剥がす | 6 |
| 微分形式 | 計量を使わずに微分と積分を作る | 8 |
| Riemann 幾何 | 計量を入れる | 8 |
| 圏論 | 中身を見ずに、関係だけで話す | 0 |

### 立つ。まだ無い

| 主題 | 何を仮定すると形が決まるか | いま | なぜ立つか |
| --- | --- | ---: | --- |
| **解析** | 完備性。Cauchy 列が収束すると仮定するだけで、縮小写像の原理が出る | **18 概念** | 縮小写像 → 逆関数定理 → 陰関数定理 → 部分多様体、が一本。ODE の存在と一意性も同じ証明。**幾何の 5 連載が既にこれに依存している**（多様体 ← 滑らかさの階層、測地線 ← ODE） |
| **代数** | 掛け算に逆元を要求するかどうか。要求を外すと環、入れると体 | 5 概念 | 体の拡大と Galois 対応まで行くと、**「角の三等分はできない」「五次方程式に解の公式が無い」が定理として出る**。できないことを言う型 |
| **代数トポロジー** | 穴を数えるのに、微分を使わない | 1 概念 | **微分形式 8 の到達点（de Rham の定理）が、位相側の $H^*$ に依存しているのに家が無い。** `de-rham-theorem` が `singular-homology` を要求している |
| **位相空間論** | 距離を捨てても「近い」が定義できるか | 8 概念 | 分離公理と第二可算を多様体の定義が要求している。いま「土台」と「位相の続き」に散っている |
| **複素解析** | 一度微分できると仮定する。**それだけで無限回微分できる** | 3 概念 | 実解析との差がそのまま主題になる。一致の定理、留数から実積分 |
| **確率過程** | 時間を入れる。条件付き期待値が現在値に等しいと仮定する | 2 概念 | 測度と確率の続き。停止時刻、Brown 運動 |

**解析が最優先。** 18 概念が既にあり、幾何の 5 連載が依存していて、
書けば全部の前提が埋まる。**新しく概念を足す必要がない。**

### 保留

| 主題 | なぜ保留か |
| --- | --- |
| 数論 | 概念 0。既存のどれとも依存が繋がらない。単独で立つが孤立する |
| 組合せ論 | 概念 0。マトロイドは計算機側にある |
| 微分方程式 | **解析へ畳む。** 存在と一意性の証明が縮小写像そのもので、独立の主題にすると同じ話を二度やる |

## 物理

いま 2 連載・8 本・18 概念。**分野グリッドの blurb は「力学・電磁気・量子・統計」と
書いてあるのに、電磁気と統計は連載も概念もゼロ。** 読者はカードを見て 4 つあると
思って入り、2 つしか無い。ここは宣言と実物が食い違っている。

### 立っている

### 立つ。まだ無い

| 主題 | 何を仮定すると形が決まるか | いま | なぜ立つか |
| --- | --- | ---: | --- |
| **統計力学** | 何を仮定したら分布が決まるか。等重率、あるいは最大エントロピー | 0 概念 | 前提は揃っている（確率空間、期待値、エントロピー）。**情報理論と同じ量が出てくる**のが主題になる |
| **相対論** | 計量が場になる。曲率が物質で決まると要請する | 概念は Riemann 幾何側にある | `einstein-tensor` と `bianchi-identity` が既にある。2026-08-20 に「数学の記事を物理のために書かない」と決めて Riemann 6 から Einstein 方程式を外した。**外した先の家がまだ無い** |

### 立てない／保留

| 主題 | 理由 |
| --- | --- |
| 電磁気 | **ベクトル解析 6 が「Maxwell 方程式が 2 本になる」を到達点にしている。** 物理側で立てるなら軸を変える必要がある（何を要請したら Maxwell が決まるか＝ゲージ不変性と相対論的共変性）。重複するので、軸を分けられるまで保留 |
| 場の量子論 | 遠い。前提が全部足りない |
