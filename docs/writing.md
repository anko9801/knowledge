# 書くときの規則

規則の文言より、下の ○/× の対を見る。**二つ以上引っかかったら、書き直しではなく組み替えを考える。**
つまらない記事にも、いい一行はもう入っている。消すより順序を替えるほうが早い。

**読者は何も持っていないし、何もしない。** 下限は中学生に置く。過去に習ったことを当てにしない。
要るものはその場で見せる。前提が要る箇所では本筋を止めず、そこだけ別の回へ逃がす。

測定の記録・負けた仮説・出典は [decisions.md](decisions.md)。ここには指示だけ置く。

## 見出しは盛らない

```
○ 順序を定義していないのに、大小が決まっている
○ 確率 0 のことが、必ず起きる
○ 情報を捨てたのに、捨てた先が保存則になる
○ 定義がおかしい／覚えることが多すぎる／全部は測れない

× $3$ という集合の中身は、$0, 1, 2$ である        事実の細部を平坦に述べている
× 空集合から数え始めて、無限を追い越す            事実を超えて格好つけている
× 条件を三つ書いた時点で、式は決まっている        従属節を足してから言うと自信が無く読める
× いちばん地味な公理が                            「地味」は書き手の評価
  → ○ 循環を禁じただけで
```

事実の側が既に驚きなので、修辞を足す余地は無い。**長さは見ない。**
効くのは、事実がそのまま驚きになっているかである。
**形を一種類に揃えない。**「A なのに B」ばかりになったら、主張ですらない不満の一言を混ぜる。

## 実例は二つ要る

「これ一般化できるのでは」が立つのは四つ揃ったときだけ。実例が二つ以上／読者が**いま使っている**もの（昔習ったものではない）／出どころがばらばらなのに同じ形／**気づくのは読者**（作者が先に答えを言わない）。

```
○ 公式集と三つの積分定理を並べてから
  「並べて書くと、どう見ても同じ形をしている。偶然のはずがない」   指は差すが、答えは言わない
× 標準模型と一般相対論を並べてから                                 読者が持っていない
× 定義を置いてから例を出す                                         気づく機会が読者に来ない
```

## つまらない側から入る

**痛みを名指して、解く。** 効くのは読者がすでに持っている痛みだけで、作った痛みはただの不快になる。
入口の動詞の主語を見る。一般化する・並べる・比べる・道具を用意する・持ち出すは**分野の中の作業**で、分野の外では何も起きない。

```
○ 覚えることが多すぎる／習わない／正直なところ、要らない
○ 全部は測れない／関数は積分できない／地図は一枚では足りない
○ 「φ ならば φ」の証明が、数行かかる
○ よく回っている班ほど、間違いを多く報告した

× 接束を一般化する／材料を並べる／引数を入れ替えてみる
× 宇宙を段階に分ける／力学の外へ／矢印から離れる
```

世間が冷遇しているものと足し算する。うまくいかない状況を先に作れば、読者は当事者になる。

**読者は、その題材をまだ選んでいない。** 初回は「なんだろう」で開かれ、動機が分からなければ閉じられる。だから入口に置ける不満は、その題材についての不満ではない。**読者がいま現にやっていることへの不満**だけである。

```
○ 最強と言われながらも、使ってみると想像以上に難しい   すでに選んだ読者には、評判を疑う
○ 一番の問題はストレスです                             選んでいない読者には、いまの不満
× なぜこの分野をやると良いのかを説明する
× その分野を一冊読んだ人にしか持てない不満から入る
```

動機は説明しない。**読者がすでに困っていることが、そのまま答えになっていると気づかせる。**

その不満が、そのまま記事の軸になる。**一本に畳んで、冒頭で宣言する。**

```
○ 最大の特徴は安定した継続火力です。便利なスキルの数々は全て、絶え間なく
  ダメージを与え続けるためにあります。逆に言えば、仕事はこれしかありません
○ ヒール性能がしょぼいということは、つまりそれ以外で価値を出せということです
○ 一番の問題はストレスです。……そのストレスそのものが、中毒にさせる要因でもある
× 特徴を三つ挙げてから、順に説明する
```

以降の節は全部その一本に紐づける。紐づかない節は書かない。

## 賭け金を置く

失われうるものを、始める前に置く。読者がいま払っている代償／著者が自分の主題を疑う／世界の側の事実。二番目がいちばん効く。

```
○ 質点や剛体を解くだけなら、解析力学はほぼ要らない
○ 便利さを売りにする限り、この形式は「不要では」と言われて仕方がない
× 座標変換が楽になり、拘束力を消せる                その題材をやる価値を前提にしている
```

**損失は三つ数える。** 一つでは重さが出ない。

```
○ 無駄な時間を使い、その間に敵のウルトが貯まり、味方との合流が遅れる。
  このたった一つの判断ミスで、とてつもない量のリソース差ができる
× 効率が悪くなる
```

## 同一視は比喩ではない

比喩は「A は B のようだ」で、差を問わない。逃げ道があるので刺さらない。
同一視は「A と B は同じだ」で、**差を全部数えた上で捨てている**。反論できる主張なので、当たれば刺さる。

```
○ 行列式は体積である／確率は測度の言い換えである
○ 行列は写像ではない／dx は微小量ではない／偏微分はテンソルにならない
× 群は対称性を測る言葉のようなものだ
```

**片側は、読者がすでに手に持っているものに置く。** 知っているかではなく、使ったことがあるか。

```
○ 仕組みとしては、ルシオのクロスフェードと全く同じです
○ 全方位に展開できる、ディバのディフェンスマトリックスです
○ 「第二の脳を構築する」と「最強のまとめノートを作る」は同じだ
× 「接束」と「累積階層」は同じだ        どちらも、読者は読んだだけで使っていない
```

同じ分野の中どうしでもよい。前の回でもよい。ただし数学の中で打つ等号は、定理が付かないなら打たない。

## 損得で書く

事実を並べない。**その事実が読者にとって得か損か**を書く。定義や性質を書いたら、すぐ後ろに「何のためにあるか」を置く。置けないなら、その定義は要らない。並べるときは数を先に言う。

```
○ このスキルの使い方は主に三つ。フランカーを牽制するため、ダイブタンクの
  エンゲージを妨害するため、そして敵の前線にプレッシャーをかけるため
○ 何もしなければルシオの四分の一、戦えば戦うほどチーム全体が硬くなる
× 前方に鎖を投げ、命中した敵を一定範囲内に拘束する
× 与ダメージに応じて、回復量が最大四倍まで上昇する
```

**気が進まない側も、進みすぎる側も、先に名指す。** 理由まで書く。

```
○ 一見するとただ自分のデスを減らすための、身勝手で冷酷なプレイに見えますが
○ 水希はフランカーではありません。キリコを思わせる華奢なデザインとトリッキーな
  テレポートを持っているせいで、つい敵の裏に回りたくなるかもしれませんが
× 孤立した味方は助けに行かないのが正解です。（そのまま次の項目へ進む）
× 水希をフランカーとして使ってはいけません
```

**断罪と処方はペアで置く。** 責めるのは行動で、読者ではない。間に、そうなる構造を挟む。

```
○ サポートの無駄な被弾は罪です → 相方が尻拭いをする → 前線へのヒールが止まる
  → 常に遮蔽物を意識しましょう
○ 真っ赤なクリティカルマークが不安を煽ってくるので、つい無駄遣いをしてしまいます
                                                        原因を読者の外に置く
× 責めて終わる／処方だけ出す
```

処方は標語にする。条件と動作だけ、十数字。

```
○ 敵が下がったら詰める。詰めてきたら下がる
○ 打たれたら隠れる／狙われたら壁に貼りつく
× 状況に応じて適切な距離を保つことを意識しましょう
```

## 反対側に立たせる

自分の側から説明したら、一度、相手の側に立たせる。

```
○ 敵の視点に立ってみてください。移動スキルを吐いたウーヤンなんて、
  ただ顔がいいだけのデクの棒です
○ 実際にやられた側の視点に立ってみると、この通り弾を当てるのは至難の業です
× こちらの手順だけを説明して終える
```

## まとめで終わらない

終わりは、**自分の主張が効かない場所**を置く場所である。読者は対照を手に入れて、主張の輪郭が見える。

```
○ それでもナブラを使う          自分の規則が効かない場所を残す
○ 導けなかったもの              自分の数字を疑わせる
○ 最後に敵のウルトへカウンターを決められれば、あなたのキャリーです
                                最後の判断を読者に渡す
○ まずはこの一つだけ守ってください。残りは、これが無意識にできてから
                                難しさを認めて、最小の一つを渡す
× 見出しを言い直した表
× 連載を閉じる挨拶
× ラベルだけの見出し（応用：、補足：）
```

`src/lib/ending.test.ts` が止める。書き直し待ちのものは一覧に載っているので、
直したらそこから消す。

**「次回は〜」は禁じていない。** 止めているのはまとめの表のほうである。

## 好悪は対象を名指す

替えのきかない一行は、いちばん読まれない末尾に埋めない。

```
○ 危機が定理に格下げされる瞬間が、私はこの分野で一番好きだ
○ 公理は真理ではなく、道具の設計仕様なのだ。この決着の仕方がかなり好きである
× 私はこの定理を知って、ようやく正則性公理が好きになった     何が好きかを名指していない

○ 初めて見たときは、うまくやったものだと唸った               場面と、体の反応がある
× 感情の結果だけを整った文で述べる                           状態の報告で、何も起きていない
```

世間の言い分は**実物のまま出して**拒否する。要約しない。やり過ごしたことは白状する。

```
○ 解析力学の教科書はたいてい、こう始まる。座標変換が楽になる、拘束力を消せる、と。
  だが、これで納得できるだろうか。私は学生のとき納得できなかった
○ 私はここを長いあいだ、記法の慣習として飲み込んでいた
```

**この型を当てにいくと必ず膨らむ。**

```
○ 圧縮の説明は、たいてい「よく出るものに短い符号を当てる」で終わる。
  それはやり方の話であって、どこまで縮むのかには答えていない。
× 同じ内容を、引用を二行に伸ばし、言い換えを二度重ねて言う
```

型は満たすものではなく、**削っても残るもの**である。

## 敬体を土台にする

文体は敬体で通す。**常体に落として強調しない。** 跳ねさせるのは語彙と長さと体言止めであって、文体の切り替えではない。

**記号でも跳ねさせない。** 題名と見出しでは、
**主題や主語の直後に読点を置かない。**

```
○ 覚えられる量は情報量では決まらない
○ 微分方程式の解の個数が穴の数である
× 重力は、座標を選べば消える
× 曲がりが、計算の二倍になる
```

読点で作った間は、事実が足りないときの埋め合わせになる。
**事実の側が既に驚きなら、溜める必要が無い。**

本文は別で、従属節の「〜と、」「〜のに、」も別である。
止めるのは題名と見出しの、主題の直後だけ（`src/lib/ending.test.ts`）。

```
○ はっきり言いましょう。サポートの無駄な被弾は罪です。
○ シールドを貼られたら終わり。隠れられたら終わり。マトリックスに食われて終わり。
× 指数を一つ上げただけで、解が無数から零になる。      一文だけ常体に落ちている
× サポートの無駄な被弾は罪である。                    全部常体では、全部が同じ強さ
```

跳ねているのは俗語（罪、クソゲー、デクの棒）と、言い切りの否定（〜しかありません、〜ではありません）である。

**一番強い語を、文の最後に置く。** そこまでを引き延ばすほど効く。

```
○ 移動スキルを吐いたウーヤンなんて、ただ顔がいいだけのデクの棒です
○ そして育ちすぎたヒーローは、誰にも止められません
× デクの棒のようなものになってしまうということです    強い語の後ろに説明が続いている
```

落とす語は短く、具体的で、俗い。切り捨てる方向の語ほど強く置ける。

**反復するなら、同じ語で落とす。**

```
○ シールドを貼られたら終わり。隠れられたら終わり。マトリックスに食われて終わり。
× 無力です。何もできません。意味がなくなってしまいます。    言い換えの反復は水増し
× $x^4$ も一つもありません。$x^5$ も一つもありません。      繰り返す側が長すぎる
```

繰り返す語は短く、変わる部分を長く取る。比が逆になると、ただの冗長になる。

短いだけでは跳ねない。「$x$ とおく。」「矛盾。」は証明の帳簿づけであって、修辞ではない。

```
○ つまり機械語が一つも出ません。排他の原語が、です。……
  ここで自分の読み違いを疑うのが、まっとうな反応だと思います。読み違いではありません。
```

証拠を目の前に置く → 読者の反応を先に代弁する → 一言で切る。

**反応は当てるもので、命じるものではない。**

```
○ ここで自分の読み違いを疑うのが、まっとうな反応だと思います
× この分野を作った人がこれなので、あまり緊張しなくていいです
× 安心してください／面白いですね／ここは重要です
```

## ちょけてよい

高級語彙を表に出し、素朴語へ翻訳する動作そのものを見せる。構文を揃える／自分を含める／言い切らない。

```
○ 多機能ノートアプリを支えているのは、実質的な生産性向上より
  「最強のまとめノートを作りたい」という中2の頃から続く永遠の欲望かもしれん
× 「第二の脳」などと言う人は、要するに中2のノート作りから抜け出せていない
```

× は自分を外している。見下しなので笑えない。禁じるのはこれだけ。

**厳密に書いたら、すぐ雑に言い直す。** 訳すだけでは足りない。格を下げる。

```
○ （仕様を正確に並べたあと）ややこしいですね。つまり波を当てると
  めっちゃ回復できるよ、ということです
× 到達不能基数とは、要するにアレフ 0 が有限に対して持っていた立場を、
  アレフ 0 に対して持つ基数である          正確だが、格が下がっていない
```

## 説明を続けない

説明が三つ続いたら、説明でないものを挟む。形は二つある。

**本筋にゼロの脱線。落ちを付けて、捨てる。**

```
○ ちなみに日本人でも島田でもないのに壁を登れる関西弁のスコットランド人がいた気も
  しますが、話がややこしくなるので見なかったことにしましょう
```

あとで回収しない。回収すると次の節の技になって、別物になる。

**いま手が動くもの。** ただし読まずに済む一手だけ。計算は作業になる。

```
○ オプションを開いて操作設定、ヒーロータブから選んで、切り替えをオフにしましょう
× 手を動かせば出ます／この式に $n$ を入れて計算してみてください
```

抽象が続いた場所に、読み終える前に実行できるものを置く。

## 算数を省かない

計算できる式は、途中を全部書く。読者が紙で追える形にする。

```
○ D = 4L - 2I に L = I - V + 1 と nV = 2I + E を代入して
  D = V(n-4) - E + 4 を出し、n = 4 で V が消えるのを見せる
× 「次数を数えると、四次では発散する構造が二つしかありません」
```

```
○ cosh(iπ) = -1、sinh(iπ) = 0 を書き、行列を二つ並べて積が -1 になるのを見せる
× 「複素のラピディティを入れると PT が恒等変換とつながります」
```

**飛ばしてよいのは、飛ばしたと書いたときだけ。**

```
○ 「一つ輪の積分そのものはここでは追わない。係数の出どころだけ数える」
× 「計算すると、この係数が出ます」
```

### なぜ足りないと困るか

省くと、**算数を省いた箇所と、本当に数値でしか出ない箇所が同じ顔になる。**

連載はどれも「何を仮定すると形が決まるか」で通し、結びは
「ここから先は出ていない」に置いている。**その境界が式の上に無いと、
主張が確かめられない。**

途中を全部書けば、どこまでが有限回の代数で、どこからが数値かが自分でも見える。

```
○ 「係数は 4/3 × 15/8 = 5/2 から出る。一方この定数は、
  非線形方程式を数値で解いて合わせた数で、代数からは出ない」
× 「係数と定数が出ます」
```

### 密度そのものを目的にしない

**式を足す作業ではない。飛ばした算数を戻す作業である。**
平文で足りている箇所に式を被せると、この節の前にある規則
（[CLAUDE.md](../CLAUDE.md) の「平文で言えることに、記号を被せない」）に戻る。

判定は一つ。**その式を消したら、主張が確かめられなくなるか。**
なるなら要る。ならないなら要らない。

### 候補の拾い方

結果へ飛んでいる箇所は、決まった言い回しで出る。

```
grep -rn "計算すると\|展開すると\|計算すれば\|計算し直すと" src/content/articles/
```

拾ったものを一件ずつ見て、**直後が結果だけか、算数が書いてあるか**を判定する。
「数えると」は本当に数えている場合が多いので、機械では分けられない。

**この判定は機械化していない。** 式の要否が主張に依るので、
`npm test` で止める形にできていない。

## 途中の結果を部品に戻す

一度使った材料を、あとでもう一度効かせる。書き出しに置いたものが終わりまで効くのが、いちばん深い。

```
○ 「3 次元で k 形式の成分は 1, 3, 3, 1 個」という数え上げが、
  外積が 3 次元限定であることにも、磁場がベクトルでないことにも効く
× 途中の結果が、途中の結果のまま終わる
```

明示しすぎると気づきが死ぬ。一度見せ、別のことで注意を奪い、忘れた頃に効かせる。
隠しすぎると、根拠のない**作者の考えていること当てゲーム**になる。両方が失敗になる幅の中に置く。

## 導入は最後に書く

節の数と回割りを先に決めない。材料を先に量産し、全部並べてから飛躍を探す。
結論は先に出すが、**先に出すのは中謎まで**。最後の飛躍は残す。

**入口は、その連載で回収できる場所に置く。** 入口で言ったことの最小の実例は初回に、残りは最終回までに置く。どちらも置けないなら、その入口は使わない。
